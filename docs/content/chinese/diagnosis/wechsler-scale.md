韦氏智力量表（Wechsler Intelligence Scale）是临床中最广泛使用的综合智力测评工具，用于全面评估儿童的认知能力结构。

<!--more-->

## 常用版本

- **WISC-V（韦氏儿童智力量表第五版）**：适用于 6–16 岁儿童
- **WPPSI（韦氏学前及初小儿童智力量表）**：适用于 2.5–7 岁幼儿

## 主要指数

| 指数 | 说明 |
|------|------|
| 语言理解指数（VCI） | 词汇、推理、理解等语言能力 |
| 视觉空间指数（VSI） | 积木、视觉拼图等空间能力 |
| 流体推理指数（FRI） | 矩阵推理、图画概念等 |
| 工作记忆指数（WMI） | 数字广度、图画广度 |
| 加工速度指数（PSI） | 符号搜索、编码等处理速度 |

## 在阅读障碍评估中的作用

阅读障碍儿童常见**加工速度指数（PSI）偏低**，以及工作记忆相对薄弱的认知侧写。韦氏量表有助于识别这些认知优劣势，为干预方案设计提供依据。
